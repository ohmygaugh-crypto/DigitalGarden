"What the user interfaces with"

Commonly referenced when discussing software applications. Nowadays human beings uniquely share an increasingly more similar shared experience than ever before. We all spend an increasingly unhealthy amount hours swiping on these glass screens. Since the "black mirror" we share is formless aside from a few buttons. Using them functionally apart of you application is actually thinking outside of the box nowadays. 

What goes on beneath this glass interface is what differentiates a daily driver vs a tombstone application. Cultural/legal nuances shape what apps get downloaded of-course, but in general I'm just trying to point out that we live in unprecedented times where the interface is being ubiquitous until we change the hardware interface we interact with. I hold the belief that we will revert to a more retro futurist tactile experience with analog buttons, but as it stands the smartphones have enabled and standardized way to build software for companies that frankly boils down to making your smartphone a multitool.

This is all self explanatory for digital natives. And interesting that Gen-Z's group up in a time where analog consumer products rapidly became extinct but, information overload is causing a niche resurgence in the Dumbphone market. Look it up.
